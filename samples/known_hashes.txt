# --------------------------------------------------------
#
# To contribute a hash:
#   1. Confirm the sample exists in MalwareBazaar or VirusTotal
#   2. Cite the public report or repository where it was documented
#   3. Note which rules it should trigger
#   4. Open a PR
#
# =====================
# Validation Notes
# =====================
#
# To validate rules against a sample:
#
#   1. Download from MalwareBazaar:
#      curl -X POST https://mb-api.abuse.ch/api/v1/ \
#        -d "query=get_file&sha256_hash=<HASH>"
#
#   2. Run YARA rules against the sample:
#      for rulefile in rules/*.yar; do yara "$rulefile" sample.bin; done
#
#   3. Expected matches per sample type:
#      - x86_stager       -> CobaltStrike_Shellcode_Stager_x86
#      - x64_stager       -> CobaltStrike_Shellcode_Stager_x64
#      - beacon_x86/x64   -> CobaltStrike_Beacon_DLL_Characteristics,
#                            CobaltStrike_ReflectiveLoader_Export
#      - reflective_dll   -> CobaltStrike_ReflectiveLoader_Code,
#                            CobaltStrike_ReflectiveLoader_Export
#      - ps1_cradle       -> Generic_PowerShell_Obfuscated_Loader
#      - hta_stager       -> Generic_HTA_VBS_Loader
#      - config_decoded   -> CobaltStrike_Beacon_Config_Decoded,
#                            CobaltStrike_Watermark_Cracked_Common
#      - malleable_profile -> CobaltStrike_Named_Pipes_Strings_Only
